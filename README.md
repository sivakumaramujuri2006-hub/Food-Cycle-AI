# FoodCycle AI — SIH 2026 Prototype

Self-contained browser prototype for the FoodCycle AI idea in the Smart India Hackathon 2026 submission by Five Solvers.

## Open
Double-click `index.html` or run `start_prototype.bat` on Windows.
No backend, API key, or internet connection is required.

## Demo flow
1. Start on **Dashboard**.
2. Click **Live Simulation** to demonstrate the full closed loop.
3. Explore **AI Waste Audit** → **Demand Forecast** → **Surplus Matching** → **Live Route** → **Impact**.
4. Use the controls/buttons to trigger each stage independently.

## Prototype integrity
- All numbers are simulated and internally consistent for the demo scenario.
- The UI avoids claiming that computer vision certifies food as safe.
- IoT readings are explicitly marked as simulated.
- Route geometry is an offline schematic; it does not imply a live external routing API.
- The matching engine uses deterministic demo candidates so the presentation remains stable.

## Source alignment
The prototype directly reflects the submission's stated concepts: real-time kitchen/food-processing waste tracking, predictive surplus forecasting, NGO/shelter routing for edible surplus, compost/biogas diversion, computer vision, demand prediction, smart matching, route optimization, IoT support, and a scale path from one institution to a national network.
